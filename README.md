# EDU OBBY 3D ONLINE

기존 EDU OBBY 3D 게임을 바탕으로 온라인 계정 저장과 실시간 플레이어 표시를 추가한 Node.js 프로젝트입니다.

## 실행 방법
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

## 인터넷에 공개하기
Node.js를 지원하는 호스팅(Render, Railway 등)에 이 폴더를 업로드하고 Build Command를 `npm install`, Start Command를 `npm start`로 설정하세요. 계정 데이터 보존을 위해 호스팅의 영구 디스크를 연결하고 `DATA_FILE` 환경 변수를 영구 디스크 경로(예: `/var/data/accounts.json`)로 지정해야 합니다. 임시 파일 시스템에서는 재배포 시 계정 데이터가 사라질 수 있습니다.

## 온라인 기능
- 서버 기반 회원가입/로그인 (비밀번호는 서버에서 scrypt 해시로 저장)
- 코인, 캐릭터, 난이도, 체크포인트 및 위치 저장
- Socket.IO를 이용한 실시간 접속자/캐릭터 동기화

## 현재 범위 및 주의
- 같은 서버 주소로 접속한 플레이어의 위치와 캐릭터가 실시간으로 보입니다.
- 게임 진행/물리/문제 정답은 현재 클라이언트에서 처리되므로 완전한 치트 방지형 서버 권한 게임은 아닙니다.
- 이전 HTML 버전의 `localStorage` 계정은 서버 계정과 자동으로 합쳐지지 않습니다. 기존 로컬 데이터는 원본 HTML 파일을 별도로 보관하세요.
- 공개 운영 전 HTTPS, 영구 저장소, 백업, 비속어/신고 시스템을 추가하는 것을 권장합니다.
